[대시보드 자동 백업 설치 — 한 번만]
1. https://script.google.com 접속 → '새 프로젝트' → 이름: 대시보드 백업
2. 왼쪽 톱니(프로젝트 설정) → 'appsscript.json 매니페스트 파일 표시' 체크
3. 편집기에서 appsscript.json 내용을 첨부 파일 것으로 통째로 바꾸기
4. Code.gs 내용을 첨부 파일 것으로 통째로 바꾸고 저장
5. 위쪽 함수 선택에서 '설치' 고르고 ▶ 실행 → 권한 승인(고급 → 안전하지 않음으로 이동 → 허용)
6. 내 드라이브에 '대시보드 백업' 폴더와 오늘 날짜 파일이 생기면 완료. 이후 매일 오전 6시 자동 저장
